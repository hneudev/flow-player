# Design references

These three images are copied from portfolio-4.0's `docs/design/references/images/` (15–17). They are **conceptual explorations, not specifications**. They are one possible visual theme, not mandatory branding.

| File | What it explores |
| --- | --- |
| `15-live-architecture-desktop.png` | Horizontal Interface → Server → Data with a returning response, paused at step 3 of 4 |
| `16-live-architecture-mobile.png` | The same flow vertically: requests downward, responses upward, controls in one column (a long section capture, not one viewport) |
| `17-live-architecture-night.png` | Night theme of the same state. Its colours are generated approximations; real contrast must be measured |

The stack labels shown in them (React, Node.js API, Search index) describe the simulation, not an audited system. These files are development references only. They are excluded from the published package by the `files` allowlist.
